# RayTracer

A ray tracing renderer implementation based on the book "RayTracing in one weekend".

## Description

This project implements a ray tracer for rendering 3D scenes with realistic lighting and materials.

## Added Features

- Basic ray tracing algorithm (Books 1)
- Added multithreading for performance enhancement
- Added Basic CLI and scene-camera data types to build once then use forever
- Added GPU Render support
